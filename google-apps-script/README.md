# 🎯 คู่มือการติดตั้งระบบ Google Sheet กลาง (Live Backup & Emergency Desk)
## โครงการ SMST Open House 2026

ระบบนี้ได้รับการออกแบบให้สร้างโครงสร้างชีท 4 หน้าตามธีมสีของโครงการ SMST (`#140B33` Deep Navy, `#FBC80E` Gold, `#4FD1A5` Mint Teal) และทำงานเป็น **Central Backup & Live Sync API** คู่ขนานกับ Supabase อัตโนมัติ โดยที่คุณ**ไม่ต้องออกแบบชีทเองแม้แต่น้อย**

---

### ⏱️ ขั้นตอนการติดตั้ง (ใช้เวลาประมาณ 1 นาที)

#### 1. สร้าง Google Spreadsheet ใหม่
1. ไปที่ [Google Sheets](https://sheets.new) เพื่อเปิดไฟล์ชีทใหม่
2. ตั้งชื่อไฟล์ที่มุมซ้ายบนว่า: **`SMST Open House 2026 - Central Backup`**

#### 2. เปิด Extensions > Apps Script
1. ที่แถบเมนูด้านบน คลิก **ส่วนขยาย (Extensions)** > **Apps Script**
2. ลบโค้ดเดิมในหน้าต่าง `Code.gs` ออกให้หมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ [`google-apps-script/Code.gs`](./Code.gs) ไปวาง
4. (ตัวเลือกเสริม) ไปที่ **การตั้งค่าโครงการ (Project Settings)** (ไอคอนรูปฟันเฟือง) ตรวจสอบให้ Time Zone เป็น `(GMT+07:00) Bangkok Time`

#### 3. รันสร้างชีทและธีมอัตโนมัติ (Setup Sheets)
1. ในหน้า Apps Script ให้เลือกฟังก์ชันที่แถบด้านบนเป็น **`setupSheets`**
2. คลิกปุ่ม **▷ Run (เรียกใช้)**
3. Google จะขอสิทธิ์อนุญาตเข้าถึงชีท (Review Permissions):
   - เลือกบัญชี Google ของคุณ
   - คลิก **Advanced (ขั้นสูง)** > คลิก **Go to Untitled project (unsafe)** / ไปยังโปรเจกต์
   - คลิก **Allow (อนุญาต)**
4. เมื่อรันเสร็จ กลับไปดูที่หน้า Google Sheet จะพบว่า:
   - ✨ **ชีททั้ง 4 หน้าถูกสร้าง จัดขนาด จัดสี และใส่ Checkbox ตามธีม SMST เรียบร้อยทั้งหมด!**
     - `🔍 Search_Checkin`: หน้าค้นหาและเช็คอินฉุกเฉินหน้าโต๊ะ
     - `Master_Attendees`: รายชื่อผู้ลงทะเบียนล่วงหน้า + เวลาเช็คอิน
     - `WalkIn_Records`: ข้อมูล Walk-in หน้างาน + ข้อมูลการเงิน
     - `Scan_Audit_Log`: บันทึกประวัติการทำรายการทุกอย่างย้อนหลัง

#### 4. เผยแพร่เป็น Web App (Deploy)
1. ในหน้า Apps Script คลิกปุ่มสีน้ำเงิน **Deploy (การทำให้ใช้งานได้)** ที่มุมขวาบน > เลือก **New deployment (การทำให้ใช้งานได้รายการใหม่)**
2. คลิกไอคอนรูปฟันเฟือง ⚙️ ด้านซ้าย > เลือก **Web app (เว็บแอป)**
3. ตั้งค่าดังนี้:
   - **Description**: `SMST Central Sync v1`
   - **Execute as (เรียกใช้ในฐานะ)**: `Me (ฉัน / อีเมลของคุณ)`
   - **Who has access (ผู้มีสิทธิ์เข้าถึง)**: **`Anyone (ทุกคน)`** *(สำคัญมาก: ต้องเลือก Anyone เพื่อให้เว็บระบบแสกนสามารถส่งข้อมูลสำรองเข้ามาได้โดยไม่ติดสิทธิ์ล็อก)*
4. คลิก **Deploy**
5. คัดลอก **Web app URL** (ที่ลงท้ายด้วย `/exec`)

#### 5. นำ URL มาใส่ในระบบแสกน (Staff Web App)
1. เปิดหน้าเว็บระบบแสกนแท็บ **จัดการระบบ (Admin)**
2. ในการ์ด **"⚡ ระบบสำรองข้อมูล Google Sheet กลาง"**
3. วาง Web App URL ลงในช่องแล้วกด **"💾 บันทึกการเชื่อมต่อ"**
4. กดปุ่ม **"🔍 ทดสอบการเชื่อมต่อ"** หรือ **"🔄 Force Full Sync"** เพื่อทดสอบส่งข้อมูลก้อนแรกขึ้น Google Sheet ได้ทันที!

### 🌟 คุณสมบัติเด่นของชีทที่ระบบสร้างให้:
- **Search Desk ทันใจ (`🔍 Search_Checkin`)**: สตาฟสามารถเลือกชื่อตัวเองที่ช่อง `B2` แล้วพิมพ์ชื่อ/เบอร์/รหัส ในช่อง `B4` แล้วติ๊ก Checkbox เช็คอินได้ทันทีในกรณีที่เน็ตระบบหลักช้า
- **Auto-Timestamp & Audit Trail**: ทุกครั้งที่มีการติ๊กเช็คอินหรือใช้ Voucher ระบบจะปั๊มเวลาประเทศไทย (`Asia/Bangkok`) ให้อัตโนมัติ
- **Safe Upsert**: เมื่อมีการอัปโหลด CSV รายชื่อใหม่ทับ ระบบจะเก็บรักษาเวลาและสถานะคนที่เช็คอินไปแล้วไว้เสมอ ไม่มีการถูกเขียนทับหาย
- **Recovery Sync**: หากเซิร์ฟเวอร์หลักมีปัญหา สามารถกดปุ่ม **"⬇️ ดึงข้อมูลเวลากลับจาก Sheet สู่ Supabase"** เพื่อดึงเวลาคนที่เช็คอินในชีทกลับเข้าสู่ฐานข้อมูลหลักได้ในคลิกเดียว
